# ✏️ כנף במחברת (Sketchbook Wing)

משחק דפדפן מצויר בעבודת יד בסגנון דף מחברת, שבו מטיסים ציפור מצוירת בשמיים, אוספים מטבעות ופותחים ציפורים, צבעים ואביזרים מגניבים בחנות!

🔗 **למשחק החי (Play Online):**  
👉 **[https://elishaygh.github.io/sketch-bird/](https://elishaygh.github.io/sketch-bird/)**

---

## 🎮 איך משחקים? (How to Play)

* **שמירה על גובה:** הציפור מרחפת באוויר ושומרת על הגובה שלה אוטומטית (בלי ליפול למטה!).
* **למעלה / למטה (`⬆️` / `⬇️` או `W` / `S`):** טיסה כלפי מעלה או מטה כדי לאסוף מטבעות.
* **ימינה / שמאלה (`➡️` / `⬅️` או `D` / `A`):** הגברת מהירות הטיסה (`מהר`) או האטה (`לאט`).
* **מסך מגע / עכבר:** ניתן לשחק גם בעזרת הכפתורים הגדולים שעל המסך בכל טלפון, טאבלט או מחשב.

---

## ✨ מה מחכה לכם במשחק?

* **שלבים מאתגרים:** בכל שלב יש כ-23 שניות לאסוף כמה שיותר מתוך **100 מטבעות** שמופיעים בצורות שונות בשמיים (גלים, קשתות, אלכסונים ועוד).
* **🎨 חנות ועיצוב הציפור (3 קטגוריות):**
  * **🐦 ציפורים:** הציפור המקורית מהציור, פלמינגו, אווז, תוכי, ינשוף ועגור אוריגמי.
  * **🖌️ צבעים:** עפרון אפור, כחול עט, אדום טוש, ירוק מרקר, סגול מלכותי וזהב נוצץ.
  * **👑 אביזרים:** כתר מלכות, כובע קוסמים, כובע מצחייה, גלימת גיבור-על, משקפי שמש ועניבת פרפר.
* **📄 החלפת דף מחברת:** אפשר לעבור בלחיצת כפתור בין דף שורות, דף משבצות או דף חלק.
* **💾 שמירה אוטומטית:** כל המטבעות והפריטים שרכשתם נשמרים אוטומטית בדפדפן.

## 🛠️ מבנה הפרויקט (Project Structure)

המשחק בנוי כולו בקובץ HTML אחד עצמאי (`index.html`) ללא תלות בספריות חיצוניות או שרתים, עם ציור וקטורי חי ב-HTML5 Canvas וצלילים מסונתזים באמצעות Web Audio API.

* `index.html` — קוד המשחק המלא (עיצוב, לוגיקה, סאונד וחנות).
* `README.md` — מדריך למשחק ולמאגר.
* `HANDOFF.md` — מסמך הקשר טכני להמשך פיתוח עתידי.
